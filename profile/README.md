One prompt. Agents do the work.

I started with one constraint: **there is only one prompt.** Not one per project, per window, or per agent. One. You type your intent there, and agents do all of the work. You stop spending cycles on switching windows and deciding where to type what.

> You don't go to the work. The work comes to you.

## Start here

- [terminal](https://github.com/new-terminal/terminal): the vision, the design, and the FAQ
- [terminal.new](https://terminal.new): the site

## Install

There is no release yet. Paste this into your agent and it will tell you where things stand:

```text
Install New Terminal from https://github.com/new-terminal/terminal. Follow the repo's AGENTS.md.
```
